One original fortune-cookie line for a software developer (114 characters),
written for the [make.fun bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44):

> The legacy code you curse was once someone's proud Friday deploy; be gentle with it, for yours will be legacy too.

## Why this line

Judged by a tired senior engineer against the brief in `RULES.txt`:

1. **Fortune-cookie wisdom, not a slogan** — one balanced sentence, two
   clauses, landing in a single breath.
2. **True about a developer's day** — legacy code, and the Friday deploy
   that produced it.
3. **A turn not heard before** — the curser becomes the cursed: the code
   you curse was once someone's proud work, and yours will be legacy too.
4. **Quiet double meaning** — "be gentle with it" is advice about the code
   and about its author at once, rewarding a second read.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Node 22,
standard library only — the program writes a constant string, no network,
no clock, byte-identical on every run. It exits non-zero if the line ever
exceeds the 120-character gate.
